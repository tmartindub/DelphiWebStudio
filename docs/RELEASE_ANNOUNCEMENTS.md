# Delphi Web Studio Pro 1.0 release announcements

Prepared November 18, 2026. These are drafts for the owner to post; preparing this file does not post to a social network.

## LinkedIn

I'm pleased to announce **Delphi Web Studio Pro 1.0**, a free, open-source Windows application for visually creating and maintaining websites.

This project grew from practical website work: arranging pages, keeping information current, organizing photographs and documents, and retaining control of the finished website files. It brings together visual editing, responsive layouts, dropdown navigation, media folders, photo galleries, calendars, staff biographies and bulletin/PDF libraries, with rich-text controls and Windows spelling support.

Optional **Google Gemini assistance** can improve selected wording, create editable pages or sections, and propose changes to existing content. You inspect the result with Preview, accept it with Apply and retain Undo. Gemini requires your own Google API key and internet access.

Projects can be saved with their media, and websites can be exported as HTML, CSS, JavaScript and assets for local testing or compatible hosting. SFTP tools are included for reviewed uploads to a suitable server.

Both **32-bit and 64-bit Windows editions** are available, together with illustrated guides. Delphi Web Studio Pro builds on **OpenPage**, created by **Federico De Ponte**, and retains its MIT license and attribution.

Download and read more: [Delphi Web Studio Pro 1.0](https://github.com/DelphiWebStudio/DelphiWebstudio/releases/tag/v1.0.0.1).

I welcome feedback from people who create and maintain websites, particularly churches, community organizations and small businesses.

**Delphi Web Studio Pro 1.0 is ready!**

I've been working on a free, open-source Windows website editor that lets you arrange text and photographs visually, organize media, build galleries, calendars and dropdown menus, and keep your own editable projects and finished website files.

Optional Google Gemini assistance can help with wording and page changes, with Preview, Apply and Undo. It requires your own Google key and internet access.
