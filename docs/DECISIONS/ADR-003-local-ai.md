# ADR-003: Local AI proposes typed actions

Date: 2026-10-29. Status: accepted direction; model/runtime unselected.

Manual editing works without AI. Optional local inference proposes typed mutations, validated and reviewed before applying, with undo. AI cannot execute arbitrary commands, directly modify files or publish. External providers require opt-in. Pin exact model/runtime revisions and license evidence before redistribution. Label template fallback honestly.
