# Static HTML folder import (experimental)

Choose **Import HTML folder** on the dashboard or in the editor, select the folder, review the report, then choose **Create HTML project**. A separate project is created; selected source files are not modified and nothing is published. The initial importer accepts up to 1,000 files, including at most 100 HTML pages, with a combined maximum of 1 MiB of UTF-8 HTML and CSS, and up to 200 supported images totaling at most 100 MiB.

The report lists recognized-reference problems and skipped files for review, including unmatched images or links and link queries or fragments that will be omitted. It shows up to 100 entries of each kind; if there are more, inspect the original folder and retained source. A report is retained in the saved project and can be reviewed from **Inspect imported source**; it retains at most 100 reference details plus the full issue count and skipped-file list. Recognized image references are based on the selected file names; each image still has to pass validation when the project is created.

The top-level `index.html` is used as Home when present; otherwise the first HTML file becomes Home. Pages get new local paths and editable content blocks; basic headings, lists and emphasis are converted. Supported images are copied into the new project's media library, with duplicates reused. Recognized local image references become image blocks, and recognized links to selected HTML pages are rewritten to the new page paths. Image files must pass the media library's format and safety checks or the import is stopped. The selected HTML and CSS text is retained as inactive project data and may contain private information. Layout, styling, scripts, link fragments and unrecognized references are not reconstructed. Other files remain in the original folder and are counted as not copied. Review every page and link before using the project. Keep the original folder.

To review retained source, open the editor's JSON/code panel and choose **Inspect imported source**. Select an HTML or CSS file to read or copy its original text; the view does not execute it. An isolated Windows WebView2 test used fictional HTML, CSS, a heading, a local page link, an SVG image, a missing image, a skipped file and a script; it checked the report, separate project, rewritten link, image reference, inactive script, local ZIP export, source retention and read-only source review after saving and reopening. The folder-selection control was enabled, but the test supplied files programmatically rather than using the system folder dialog. Broader site compatibility and clean-Windows acceptance remain unverified.
