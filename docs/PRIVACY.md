# Delphi Web Studio Pro privacy notice

Last changed: 2026-11-16

This notice describes Delphi Web Studio Pro 1.0.0 build 1 for Windows. Third-party services, browser builds, and future versions fall outside its scope.

## Information kept on this computer

The editor displays its interface in Microsoft Edge WebView2, a browser engine embedded in the Windows application. It stores local project drafts and settings in that browser's storage. Imported media and local revisions are stored in local browser databases. A project saved to a file contains its project content and, when applicable, packaged media. WordPress is a website content-management system whose exports describe content in XML, a structured text format. Imports from WordPress or existing website folders can retain those records, HTML page structure and CSS styling as inactive project data; those files may include private author details or other information. Backup and recovery files may also contain private project content. Protect the computer and any files you share or back up.

The optional online AI tools use Google Gemini, Google's artificial intelligence service. Its API key is a secret credential that identifies the Google project making a request. A Deploy Access Key is a separate credential for a hosting service. Gemini and Deploy Access Keys entered in Settings are held in memory for the current session. On Windows, **Save key** also stores the Gemini key in Windows Credential Manager for the current Windows account so it can be reused across projects and restarts. **Remove saved key** removes the Windows copy. Older keys saved in browser storage or project settings remain until removed with the corresponding legacy-key control. The Windows credential is separate from project files and website exports. The deployment key is excluded from portable project files. Testing a Gemini key sends the key and a test request to Google. Authentication is sent in a request header, rather than in the request URL.

## Network use

The optional **Help with selected text** command sends only the highlighted passage and the user's writing instruction to Google after explicit consent and confirmation that the key's project has billing disabled. It reads the saved Windows credential, uses Gemini 3.5 Flash-Lite, and keeps previews in memory. Apply changes only the selected text through the editor's undoable project state; it does not publish or send other pages or media. Free tier is Google's limited service allowance for an eligible project. Google may use free-tier content to improve its products. Free tier is determined by the Google project's billing status, which the application cannot verify from an API key. See [Gemini text assistance](GEMINI_TEXT_ASSISTANCE.md) for controls and limits.

Local AI uses a model, the software that generates suggestions, on this computer. Its runtime is the program that loads and runs that model. The optional local AI feature runs the selected model as a local process bound to the computer's loopback interface, an address accessible from this computer. Downloading its runtime or model opens a browser and contacts the selected download provider. The separate cloud-generation path is off by default; if enabled for the current session, it can send a generation brief to Google when a key is available or to a configured server endpoint. The setting resets on reload. Do not include private content unless you intend to send it. SFTP (SSH File Transfer Protocol) is the encrypted file-transfer connection used for website uploads. The optional SFTP functions connect to the configured server when requested. Opening, saving, previewing and exporting a project do not publish a website. Review any links, custom code, external media or configured third-party services in a project: these may contact external services when used or viewed.

**Open reviewed site in browser** serves the reviewed website ZIP to a browser on this computer over a temporary loopback address. The preview can load external resources referenced by the site. The temporary ZIP is removed when you stop the preview or close the editor. The Microsoft Edge WebView2 Runtime may collect and send diagnostic information as described in [Microsoft's WebView2 data and privacy documentation](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/data-privacy).

The optional **AI assistant** creates pages and sections and proposes edits to existing components. Creation sends the request, supplied facts, a bounded text extract from one reference page, selected theme values and page names/addresses. Existing-edit mode sends the selected target's listed properties and text, page names/addresses, and up to six recent requests/results with their review states. Selecting the whole page includes that page's components. With separate catalog permission, filenames, logical folders, types, dimensions and asset IDs are included so existing media can be selected. Original media bytes, local paths, other pages' body text, raw HTML, credentials and saved connection settings are excluded. Selected content can still contain private wording; review the sharing statement before sending it. The saved key authenticates in a header. Preview leaves the project unchanged; Apply commits a reviewed, undoable transaction. Conversation and proposals stay in memory in the window. This command cannot execute generated code, publish, upload files or send email. See [Gemini assistant](GEMINI_ASSISTANT.md) for controls and limits.

## Retention and removal

Uninstalling the application preserves saved projects, the WebView profile, local revisions, the Windows credential, and optional AI files. Dashboard → **Local Storage** lets you review local media and revision sizes and explicitly remove local revisions or media left by a removed draft. Removing browser/profile data may permanently remove local drafts and media. First save and verify separate project files and backups.
