# Contributing

Use feature branches and small PRs against this fork. Preserve MIT attribution/history and follow owner directives and docs/DECISIONS.

Verify Git/remotes and create the required ZIP pre-change backup. Native forms remain IDE-editable; React canvas is the approved exception. Avoid unnecessary helpers/dependencies. Product colors are orange/blue; exclude payments/ecommerce and mandatory cloud access.

Run npm ci, npm run lint, npm test, npm run build and review npm audit. Verify browser behavior, keyboard use, save/reopen and offline output for relevant changes. Exercise legacy/five-page/unknown-content/recovery fixtures for migrations. Describe remaining failures honestly.

Commit only intended files and push validated changes to every configured backup repository. Do not force-push/rewrite history. Never publish user sites during routine tests. PRs describe the problem, resulting behavior, validation and limitations.
